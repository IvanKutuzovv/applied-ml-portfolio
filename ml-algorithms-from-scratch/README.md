# ML-алгоритмы с нуля

Три небольших проекта об одном и том же: реализация ключевых ML-алгоритмов на чистом NumPy, с прямым сопоставлением против эталонных библиотек (scikit-learn, XGBoost, LightGBM, CatBoost). Цель — не переизобрести библиотеку, а разобраться, что именно происходит внутри `fit()`, и уметь осознанно объяснить и продиагностировать поведение модели, а не только вызывать её с параметрами по умолчанию.

## Состав

| Папка | Что внутри |
|---|---|
| [`01-gradient-descent`](01-gradient-descent) | Vanilla GD, SGD, SAG, Momentum, Adam, LR-расписания, аналитическое решение (нормальное уравнение + SVD), L2-регуляризация, альтернативные функции потерь (LogCosh, Huber) |
| [`02-decision-trees-bagging`](02-decision-trees-bagging) | Решающее дерево (критерий Джини, Target Encoding категорий) с нуля, bias-variance разложение бутстрапом, эффект бэггинга |
| [`03-gradient-boosting`](03-gradient-boosting) | Градиентный бустинг с нуля: ordered target encoding, bootstrap-регуляризация, GOSS, DART, квантизация признаков, feature importance, калибровка вероятностей |

Каждая папка содержит свой ноутбук, вспомогательные `.py`-модули и краткое описание итогов внутри самого ноутбука (интро и заключение).

**Почему это единый проект.** Это последовательное углубление в одну и ту же механику: сначала оптимизация параметров линейной модели, затем нелинейные базовые алгоритмы и их ансамблирование, затем — то, как эти базовые алгоритмы объединяются в бустинг и какие практические приёмы (регуляризация через сэмплирование, квантизация, ранняя остановка) делают промышленные библиотеки быстрыми и устойчивыми к переобучению.
