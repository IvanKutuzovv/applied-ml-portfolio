# Applied ML Portfolio

Девять проектов по прикладному машинному обучению. В каждом — постановка задачи, реализация ключевого алгоритма (часто с нуля, без готовых библиотек) и разбор результатов.

Темы: детекция редких событий при сильном дисбалансе классов, feature engineering на больших данных, интерпретируемость моделей, масштабируемые алгоритмы, решение дифференциальных уравнений нейросетью.

## Проекты

| Проект | Задача | Где ещё это применимо |
|---|---|---|
| [`fraud-anomaly-detection`](fraud-anomaly-detection) | Детекция мошеннических транзакций при дисбалансе классов 1:580. С нуля реализован Extended Isolation Forest, сопоставлены SMOTE/undersampling/взвешивание, unsupervised-оценки использованы как признаки для CatBoost. | Детекция редких дорогостоящих событий с высокой ценой пропуска — потери и хищения в распределённых сетях, мошеннические операции, редкие отказы оборудования. |
| [`risk-scoring-feature-engineering`](risk-scoring-feature-engineering) | Feature engineering и скоринг бинарного события на ~700 000 наблюдений. Кастомные трансформеры, агрегации временных рядов, целевая метрика — коэффициент Джини. | Джини — стандартная метрика скоринговых моделей в риск-менеджменте; методология построения признаков из разнородных источников переносится на скоринг напрямую. |
| [`grid-geo-clustering`](grid-geo-clustering) | Кластеризация географически распределённых объектов инфраструктуры (сеть остановок с учётом графа маршрутов) и тематическое моделирование текстов; отдельно — работа при 5% размеченных данных. | Зонирование обслуживания сетевой инфраструктуры, кластеризация однотипных объектов, работа в условиях дорогой или неполной разметки. |
| [`physics-informed-nn`](physics-informed-nn) | Separable PINN для решения 3D-уравнения Гельмгольца (снижение вычислительных затрат с $O(N^d)$ до $O(Nd)$); классификация звука по мел-спектрограммам. | Быстрая суррогатная модель вместо дорогого классического солвера (МКЭ/МКО) для расчётов теплового/электромагнитного/механического поля в оборудовании и инфраструктуре. |
| [`model-interpretability`](model-interpretability) | Систематическое сравнение методов интерпретации моделей: ICE/PDP/ALE, permutation importance, occlusion-based важность, SHAP и LIME (включая собственную реализацию LIME). | Там, где решение модели должно быть объяснимо аудиту или внешней проверке; проект показывает, какие методы объяснения надёжны, а какие вводят в заблуждение. |
| [`two-stage-recommender`](two-stage-recommender) | Двухэтапная рекомендательная система: memory-based и LFM (ALS/SGD/iALS) кандидатогенераторы + ранжирование CatBoost (Classifier и Ranker). | Архитектура «дешёвый кандидатогенератор + дорогой ранжировщик» — основа промышленных систем персонализации при больших каталогах и миллионах пользователей. |
| [`scalable-kernel-classification`](scalable-kernel-classification) | Аппроксимация ядер (Random Fourier Features, ORF, FastFood) как масштабируемая альтернатива ядровому SVM; сравнение с градиентным бустингом. | Там, где точные ядровые методы не масштабируются на большие объёмы телеметрии/транзакций, RFF даёт управляемый компромисс между качеством и вычислительной стоимостью. |
| [`em-latent-variable-modeling`](em-latent-variable-modeling) | EM-алгоритм для агрегации мнений экспертов (модель GLAD) и обучения выравнивания слов между языками без разметки соответствий. | Агрегация разметки нескольких асессоров с автоматической калибровкой доверия, извлечение скрытых соответствий между разнородными источниками данных. |
| [`ml-algorithms-from-scratch`](ml-algorithms-from-scratch) | Градиентный спуск (5 вариаций), решающие деревья, bias-variance разложение и градиентный бустинг (GOSS, DART, квантизация) — всё с нуля на NumPy, с сопоставлением против sklearn/XGBoost/LightGBM/CatBoost. | Демонстрация того, что происходит внутри `fit()` промышленных библиотек — база для осознанного тюнинга и диагностики моделей в проде. |

## Как читать проекты

Каждый ноутбук самодостаточен: в начале — постановка задачи и область применения, в конце — раздел с итогами. Код и текстовые выводы (в т.ч. интерпретация графиков, разбор ошибок) — часть исследовательского процесса, а не только результат.

## Стек

- **Язык и вычисления:** Python, NumPy, pandas, SciPy
- **Классический ML:** scikit-learn, CatBoost, XGBoost, LightGBM, imbalanced-learn, category_encoders
- **Deep Learning:** PyTorch, torchaudio/librosa (аудио-признаки)
- **Интерпретируемость:** SHAP, LIME, pyALE
- **NLP / тематическое моделирование:** gensim
- **Гиперпараметрическая оптимизация:** Optuna
- **Автоматический feature engineering:** featuretools
- **Гео и визуализация:** folium, matplotlib/seaborn, t-SNE
